# 踩坑清单：触发条件、定位、修正与复验

| 触发条件/观察 | 排查步骤 | 修正与复验 | 适用边界 |
|---|---|---|---|
| 目录有 PASS，但源码/清单版本不同 | 对比版本、top、配置、报告阶段与哈希；检查日志是否属于本轮 | 重新生成对应证据与清单，保留旧报告为历史；先 INCOMPLETE 再运行 | 哈希相同也不证明当前硬件已加载 |
| 把首轮报告当最终验收报告 | 对比报告头的 Routed、Design、日期与来源目录；检查 WNS/TNS | 使用最终实现数据；本工程首轮 main WNS=-0.164 ns，最终 1.058 ns | 不用改约束掩盖真实违例，不承诺同样修改适用于其他路径 |
| 内部时序为正却有 TIMING-18 | 查 no_input_delay/no_output_delay、接口时钟和实际接收设备要求 | 记录缺项、补充真实接口约束与测量方案；保留告警 | 当前 16 个外部输出延时缺项不能由内部 WNS 通过消除 |
| LUTAR-1 复位提示 | 沿 reset_guard 跟踪异步断言与同步释放，核对厂商 IP 与 RTL | 分析其结构与使用边界，保留未解决提示并补实际释放验证 | 不能只删除复位或静默降级告警 |
| 多模块各自运行后相位关系难以证明 | 观察公共参考、独立载波和运行许可；检查重启相位 | 从共享时间轴定义局部相位，逐拍核对与长时间漂移 | 载波相位与基波相位不同；不能套用本工程 60 度到所有系统 |
| 状态常量出现截断或宽度歧义 | 列出常量位宽、实际编码和比较位宽；查看编译告警 | 使用与状态向量一致的显式位宽，本工程改用 6 位二进制；跑边界和异常回归 | 不以常量改写代替状态可达性分析 |
| r=500 时“直通脉冲数量变少” | 核对相邻半开窗口，统计时间并集而非标签数量 | 比对每单元每周期有效时间、首末拍和并集；D=0.2 目标 2000 拍 | 只适用于已冻结的准 Z 源调制语义，不能推广为普通 H 桥允许直通 |
| 新 D0 与旧 D0 波形错一拍 | 核对采样、流水级、互锁与最终许可，而不是立即改比较器 | 分别验证行为契约；说明延迟差异，不沿用旧等价结论 | 同值不等于同拍；若系统要求逐拍等价必须重新设计并验证 |
| 按钮长按、跨复位或故障同拍自动启动 | 查看释放武装、事件脉冲、fault latch 和清除优先级 | 加入长按/抖动/同拍/故障后重启测试；清除不能自动启动 | 按钮模拟故障不替代独立过流保护 |
| 换路径后 MEM 或 BD 依赖丢失 | 检查相对路径、综合工作目录、MEM basename 和预设脚本 | 用打包 MEM 复制到运行目录，检查完整依赖，再从零创建工程 | 仅打开 XPR 成功不足以证明可复现 |

来源为现有 optimization_notes、coverage、design_overview、warnings_review 与报告；本表不表示每一行都曾造成硬件事故，也不将观察重新包装成未经记录的历史故障。
